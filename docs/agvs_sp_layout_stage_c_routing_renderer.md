# AGVS-SP 新布局 Stage C：正交路由与独立 PNG 渲染器

日期：2026-07-29

## 本阶段结论

Stage C 已实现一条与旧渲染器完全分离的新管线：

`AttackGraph → Visual IR → branch-aware planner → orthogonal router → PNG`

本阶段只处理视觉表达，不修改专业版 v1.4 的报告提取、事件/前置条件
判断、ATT&CK Technique、Mitigation、评分或因果关系。新渲染器尚未接入
`app.py` 或 `student_app.py`；因此应用当前仍可继续使用旧渲染器，直到新
管线完成最终切换验收。

## 新增实现

### `src/layout_router.py`

路由器把 Stage B 的节点坐标和逻辑端口转换为可绘制的正交折线。

- 所有因果线只允许向下或水平移动，禁止向上回流；
- 节点矩形/椭圆的外接框被视为障碍物；
- 使用可见性网格与 Dijkstra 搜索局部路径；
- 代价函数惩罚折弯、与已有线交叉及线段重叠；
- 路径经过简化，删除重复点与无意义的共线中间点；
- 每个有父节点的视觉目标恰好对应一个 `RoutedConnector`。

逻辑语法固定如下：

- `AND`：多条输入先汇入一条公共水平线，再以一条向下箭头进入目标；
- `OR`：每条输入使用独立端口与独立箭头，不共享公共线；
- `SINGLE`：一条独立路径与一个向下箭头。

这与导师的要求一致：无需显示文字 “AND/OR”；连接到同一公共线表示
AND，彼此分开的输入表示 OR。

### `src/layout_renderer.py`

新的 Pillow 渲染器只消费已经验证的 Stage A/B/C 数据，不重新推断语义。

- 行为/event：白底矩形；
- 状态/precondition：白底椭圆；
- tactic/阶段：淡紫色圆点 `#B8B5EA`；
- likelihood/评分：青蓝色圆点 `#31A8C4`；
- ATT&CK Technique：浅粉色标签 `#F3B2B2`；
- Mitigation：浅橙色标签 `#E7BE9B`；
- 节点和连线：`#303030`；
- Technique、Mitigation 和阶段图例固定在主图右侧独立区域；
- 主图与图例之间保留 34px 空白隔离区；
- 最小画布为 1248×710；
- 分页桥接状态保留 `continued from part N` /
  `continues in part N` 显示说明。

## 与 Stolen Pencil 和参考文献的关系

Lallie 等人的综述说明攻击图视觉配置并不存在唯一全球标准。因此，本项目
不宣称论文规定了唯一语法，而是采用论文中支持理解性的基本原则，并把导师
提供的 Stolen Pencil 固定为项目视觉金标准：

- 自上而下的因果方向；
- 行为矩形、状态椭圆；
- 顶部独立准备分支；
- 清晰的汇合与并行结构；
- 主图与图例隔离；
- 少量固定颜色承担标签层级，而非装饰。

LLM 仍只负责语义生成与分类；视觉拓扑、端口、路由和分页均由确定性代码
控制。
